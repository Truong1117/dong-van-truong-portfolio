# Dong Van Truong Portfolio

Static portfolio site for Dong Van Truong, an E-commerce Full-Stack Developer.

## Run locally

Open `index.html` in a browser, or serve this directory with any static HTTP server.

## Deploy

This repository is configured for zero-build deployment on Vercel. Import the GitHub repository into Vercel with the `Other` framework preset, leave the build and output fields empty, then deploy. Pushes to `main` publish the production version.
